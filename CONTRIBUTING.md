# Contributing to Liberty

Thank you for helping test and improve Liberty.

## Before opening a change

1. Do not include personal data, credentials, signing keys, APKs, or device logs containing account information.
2. Keep Liberty local-first: no analytics, advertising, telemetry, dynamic code loading, or `INTERNET` permission.
3. Preserve the Android managed-profile security boundary and the official-signature checks.
4. Do not change screenshot or screen-recording behavior without an explicit product decision.
5. Run `./gradlew :app:lintRelease` before submitting a pull request.

Use a normal Issue for bugs and compatibility reports. Report security vulnerabilities privately through GitHub Security Advisories as described in `SECURITY.md`.
