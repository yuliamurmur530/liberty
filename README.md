# Liberty

[English](README.en.md) · [Политика приватности](PRIVACY.md) · [Безопасность](SECURITY.md)

> **Статус: публичная альфа.** Liberty проходит открытое тестирование. Открытый исходный код улучшает проверяемость, но не является сертификатом безопасности и не гарантирует отсутствие ошибок.

Liberty — лёгкий локальный DPC-контроллер, который создаёт системный рабочий профиль Android. Root не нужен: границу между личным и защищённым пространством создаёт сама операционная система.

Официальный Android package name: `net.crinoidea.liberty`. Официальный домен: `https://liberty.crinoidea.net`.

## Что уже работает

- понятная настройка защищённого пространства;
- создание рабочего профиля через системный экран Android;
- установка приложений через Google Play рабочего профиля;
- отображение фактического состояния отдельного системного кода рабочего профиля;
- собственный экран Liberty со всеми фактически добавленными приложениями;
- локальная проверка признака VPN и HTTP-прокси перед запуском приложения без доступа Liberty в интернет;
- фактическая проверка критических правил изоляции: зелёный статус показывается только после подтверждения Android;
- отдельные аккаунты, хранилище и идентификаторы приложений внутри профиля;
- запрет межпрофильного буфера обмена, поиска контактов и доступа личных слушателей к уведомлениям профиля;
- отдельный системный код рабочего профиля и немедленная блокировка;
- подтверждённое удаление защищённого профиля и последующий системный диалог удаления Liberty;
- отсутствие рекламы, аналитики, SDK сторонних компаний и разрешения `INTERNET`;
- отсутствие `QUERY_ALL_PACKAGES`: видимы только приложения, отвечающие на запрос запуска;
- интерфейс на стандартных бесплатных шрифтах Android без загружаемых шрифтов;
- тяжёлая работа со списком приложений выполняется вне UI-потока.

## Честные границы

Один рабочий профиль отделяет все помещённые в него приложения от личного профиля. Приложения внутри одного рабочего профиля не получают доступ к чужим данным, но могут обнаруживать друг друга, если Android и их декларации видимости пакетов это разрешают. Изоляция «отдельный Android-профиль на каждое приложение» несовместима с простой установкой и обычно недоступна обычному приложению без привилегий производителя.

Liberty не устанавливает, не останавливает и не скрывает VPN. Android и прошивки производителей могут маршрутизировать или обнаруживать VPN по-разному. Надёжное автоматическое отключение либо обход туннеля требует явной интеграции со стороны самого VPN-приложения.

Обычному стороннему APK Android не разрешает клонировать уже установленное приложение в личный рабочий профиль. Кнопка «+» в системной папке Android может лишь добавить туда ярлык личного приложения; это не делает приложение изолированным. Надёжный способ — установка через Google Play внутри рабочего профиля. У настоящей рабочей копии Android показывает значок портфеля.

В зависимости от реализации Android после установки в рабочий профиль в списке приложений могут остаться две копии либо личная копия может исчезнуть из общего списка. Liberty не считает обычный значок признаком изоляции: пользователь должен запускать копию внутри Liberty, отмеченную системой значком портфеля.

Папка рабочего профиля на домашнем экране принадлежит системному лаунчеру. Liberty не может закрепить её положение или запретить оболочке разложить ярлыки на рабочем столе. Стабильным интерфейсом служит собственный экран «Защищённое пространство» Liberty.

Android не даёт обычному приложению надёжно сделать запись экрана чёрной, одновременно разрешая обычные скриншоты: системная защита `FLAG_SECURE` блокирует оба способа. Поэтому текущая версия не блокирует скриншоты и не заявляет отдельную защиту от записи экрана.

Выбор другого PIN на основном экране блокировки для открытия другого домашнего экрана — привилегированная функция прошивки (как Xiaomi Second Space), а не возможность обычного APK/DPC. Liberty использует поддерживаемый Android вариант: отдельный системный код рабочего профиля и привычный интерфейс внутри него.

## Сборка для разработчиков

Требования: JDK 17+, Android SDK 36. Проект использует Gradle Wrapper и Android Gradle Plugin 8.11.1.

Дистрибутив Gradle закреплён официальной SHA-256 контрольной суммой, а wrapper JAR проверяется в CI. Release-подпись считывается только из переменных окружения; ключ и пароли в репозиторий не входят.

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:assembleRelease
```

Отладочный APK `app/build/outputs/apk/debug/app-debug.apk` предназначен только для локальной разработки и проверки изменений кода. Пользователям и внешним тестировщикам нужно скачивать официальный подписанный файл `Liberty-<версия>-release.apk` со страницы [GitHub Releases](https://github.com/yuliamurmur530/liberty/releases).

Официальные релизы подписываются отдельным production-keystore, который хранится вне репозитория. Debug-сертификат не используется для распространения.

## Проверка на устройстве

Проверять создание профиля лучше на тестовом Android 9–16 без уже существующего рабочего профиля. Создание и удаление рабочего профиля меняет локальное состояние устройства; перед тестом важные данные следует сохранить.

Сценарий приёмки:

1. Для пользовательского тестирования установить официальный подписанный release APK со страницы [GitHub Releases](https://github.com/yuliamurmur530/liberty/releases). Debug APK допустим только разработчикам на тестовом устройстве.
2. Подтвердить системное создание рабочего профиля.
3. Установить 1–2 тестовых приложения через Google Play рабочего профиля и проверить наличие значка портфеля.
4. Установить отдельный код профиля.
5. Проверить запуск приложений, блокировку, отсутствие межпрофильного копирования и уведомлений в личных слушателях.
6. Проверить действие «Удалить Liberty и пространство»: после двух предупреждений должен удалиться только рабочий профиль, затем Android должен предложить удалить личную копию Liberty.

Обычное удаление личной копии APK не является полным сбросом: Android не даёт удаляемому приложению надёжно обработать собственное удаление, поэтому рабочий профиль может сохраниться. Для полного удаления используется действие внутри Liberty или системное удаление рабочего профиля.
